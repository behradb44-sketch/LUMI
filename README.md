# LUMI — Unified Web + Server

این نسخه یک ریپوی واحد برای بازی LUMI است: فرانت‌اند، WebSocket server و سیستم Room همگی داخل همین پروژه قرار دارند.

## اجرا

```bash
npm install
npm start
```

سپس `http://localhost:10000` را باز کنید.

## Deploy روی Render

- نوع سرویس: **Web Service**
- Build Command: `npm install`
- Start Command: `npm start`
- نیازی به دیتابیس نیست.
- پورت از متغیر `PORT` که Render تنظیم می‌کند خوانده می‌شود.

## Room System

- 10 اتاق عمومی دائمی: `LUMI-01` تا `LUMI-10`
- حداکثر 20 بازیکن در هر اتاق
- ساخت اتاق از همان دکمه `CREATE ROOM`
- اتاق خصوصی در `LIST OF ROOMS` نمایش داده نمی‌شود.
- صاحب اتاق لینک دعوت را می‌بیند و لینک مستقیماً اتاق را باز می‌کند.
- اتاق‌های عمومی دکمه `ENTER ROOM` دارند.
- اتاق‌های دائمی حداقل 2 بازیکن می‌خواهند؛ بعد از رسیدن به حداقل شروع می‌شوند، و اگر تا 5 دقیقه حداقل بازیکن جمع نشود، 3 دقیقه فرصت اضافه دارند؛ در پایان زمان اضافه، بازی با تعداد حاضر شروع می‌شود.

## نکته

این پروژه بدون دیتابیس است؛ Roomها فقط تا زمانی که سرور در حال اجراست در حافظه نگه داشته می‌شوند.
